
# Executives in Politics — Replication

This repository contains a Python-based replication of selected empirical analyses from “Executives in Politics.” The analysis is implemented in a Jupyter Notebook, using the datasets associated with the original study.

The project reproduces selected descriptive statistics, figures, and regression analyses from the paper and compares the replicated results with the results reported in the original publication.

The repository is organized to make the analysis, data documentation, generated results, and replication comparison easy to follow and reproduce.
